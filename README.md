### hh_parser
Приложение по поиску скиллов по заданной вакансии, реализовано во Flask приложении: app_parser.py
html файлы в папке templates, Стили и картики папка static
    Главная страница с описанием
    Страница заполнения формы: Город, Вакансия, Тип занятости
    Страница с результатами поиска
    Страница истории запросов

Реализовано сохранение запросов в БД (SQLite) с помощью библиотеки Алхимия
Парсер так же реализован в ТГ-боте: tg_parser_bot.py
